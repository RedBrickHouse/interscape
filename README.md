# INTERSCAPE

Presentation website for INTERSCAPE, a story-driven action adventure developed by ROOMTONE Games.

- Preview: https://redbrickhouse.gg/interscape/
- Steam: https://store.steampowered.com/app/3093160/INTERSCAPE/
- Developer: https://www.roomtonegames.com/

## Development

Static HTML, CSS and JavaScript with Korean, English and Simplified Chinese content. No build step or external JavaScript framework.

```sh
python3 -m http.server 8117 --bind 127.0.0.1
```

Open http://localhost:8117/. Use `?lang=ko`, `?lang=en` or `?lang=zh` to select a language.

GitHub Pages serves the root of the `main` branch. The review version retains `noindex, nofollow` metadata.

## Presentation

The opening uses the official floating-astronaut artwork, with the title above and the invitation below. Full-width story and gallery landscapes blend into a slate background; gameplay abilities use keyboard-accessible tabs, independently of the two playable video examples. News appears as a compact editorial list.

Slow decorative fog pauses outside the viewport, behind dialogs, in hidden tabs, and when reduced motion or data saving is enabled. The background-motion button also pauses it manually. Text, native video controls and enlarged screenshots stay sharp.
